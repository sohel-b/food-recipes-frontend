# Adapt_Ready - Frontend 🍽️

This is the frontend part of the **Adapt_Ready** project — built with **React.js**.

## 🔥 Features

- Search dishes with auto-suggest by name, ingredients, or region
- View dish details (ingredients, timings, origin, etc.)
- Paginated, sortable, and filterable dish list
- Dish suggester: find what you can cook based on available ingredients

## 🛠 Tech Stack

- React (functional components with hooks)
- Axios for API communication

git clone https://github.com/sohel-b/food-recipes-frontend.git
